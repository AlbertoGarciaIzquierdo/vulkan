# Vulkan game engine
Vulkan game engine

As I dont really like all the temporal features and AI content I am trying to create my own small 3D engine.
It's just for fun. I don't think this will be finished.

But, I am kinda tired of all the DLSS, TAA, FSR... and those kind of things.
I feel like in the 2010s the games were crispier, even with FXAA.

I cannot stop seeing all the ghosting that is being generated by all the new "technologies" because the lack of optimization in videogames.

I don't know how to call my engine... SharpEngine, CrispEngine, Sharp3D, Crisp3D... I don't know.

## IMPORTANT
LINUX: You need to install the dependencies in Dependencies.sh and install-vulkansdk.sh (This is executed with source. ex: source install-vulkansdk.sh)

The vulkanSDK downloaded from the official page https://vulkan.lunarg.com/sdk/home#linux.

PLEASE: Read the scripts before executing them, don't trust what people write in scripts.
If you don't trust the previous link, search for VulkanSDK and I think is the first link of the LunarG.
