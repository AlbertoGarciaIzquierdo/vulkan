# Vulkan game engine
Vulkan game engine

As I dont really like all the temporal features and AI generated content. I am trying to create my own small 3D engine.
It's just for fun. I don't think this will be finished.

But, I am kinda tired of all the DLSS, TAA, FSR... and those kind of things.
I feel like in the 2010s the games were crispier, even with FXAA.

I cannot stop seeing all the ghosting that is being generated by all the new "technologies" because the lack of optimization in videogames.

I don't know how to call my engine... SharpEngine, CrispEngine, Sharp3D, Crisp3D... I don't know.

## IMPORTANT
### Linux
Install the packages for your distribution from `Dependencies.sh`, then install the Vulkan SDK. The helper script is Linux-only and must be sourced from the repository root:

```sh
source install-vulkansdk.sh
```

Download the Vulkan SDK from the [official LunarG page](https://vulkan.lunarg.com/sdk/home#linux).

### Windows
Install the [Vulkan SDK for Windows](https://vulkan.lunarg.com/sdk/home#windows), CMake 3.20 or newer, and Visual Studio 2022 with a C++ compiler that supports C++26 and the Windows SDK. Install GLFW 3 with [vcpkg](https://github.com/microsoft/vcpkg):

```powershell
vcpkg install glfw3:x64-windows
```

Configure CMake to use vcpkg's toolchain file. Make sure `slangc` is available on `PATH`; install the Slang compiler separately if it is not included with your Vulkan SDK. Do not run the Linux `Dependencies.sh` or `install-vulkansdk.sh` scripts on Windows.

Read installation scripts before running them.
